# ERP AI Automation Platform

A DianApps case study showing how an AI-powered query and automation layer can make an existing construction ERP easier to use without replacing the underlying system.

## The challenge

A construction client had more than 15,000 expense records, invoices, timesheets, payroll data, accounts receivable data, and project-cost information inside a 12-year-old ERP environment.

The information existed, but answering questions such as “Which projects are losing money?” required manual reporting work and could take several days.

## The DianApps solution

DianApps built an intelligence layer on top of the client’s existing ERP.

The solution included:

- 62 query points.
- 14 departments.
- Payroll, invoices, job costs, and accounts receivable.
- Plain-English questions.
- Answers tied to real transactions.
- No SQL requirement for business users.
- No IT ticket for routine queries.

## Outcomes

- Month-end close went from days to hours.
- Cost overruns began getting detected earlier.
- Project leaders could ask questions and receive answers in seconds.
- Finance teams spent less time manually pulling and reconciling reports.
